Hydroacustics: synthetic field modeling
======================================= 

This example demonstrates how to use the topophone2 package to model an hydroacoustic field. 
An hydroacoustic field is a type of acoustic field that has equal intensity in all directions. 
In this example, we will create a simple model of an hydroacoustic field and visualize its characteristics.
