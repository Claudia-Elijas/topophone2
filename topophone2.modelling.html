Modelling module#

The topophone2.modelling module provides functionality for array-covariance modelling. It contains the ArrayCovarianceModel class to predict the array covariance for a given geometry and frequency vector recording any combination of energy distributions:

  • point (plane wave)

  • normal distribution

  • skew-normal distribution

  • spherically-/cylindrically-harmonic field.

class topophone2.modelling.ArrayCovarianceModel(x: ndarray, freq: ndarray, sigs: list, weight_units: str = 'dB', calc_noise_only: bool = False, custom_cf: Dict[str, Tuple[int, Callable]] = {})[source]#

Class to model the array covariance for a given geometry and frequency vector recording any combination of energy distributions: point (plane wave), normal distribution, skew-normal distribution, and spherically-/cylindrically-harmonic field.

Methods

  • cf_point() : characteristic function for point (plane wave)

  • cf_normal() : characteristic function for normal distribution

  • cf_skewnormal() : characteristic function for skew-normal distribution

  • cf_isonoise() : characteristic function for isotropic noise

  • cf_noise2D() : characteristic function for 2D noise

  • cf_noise3D() : characteristic function for 3D noise

  • forward() : predict array covariance for a given model vector

Input:

  • x (numpy.ndarray) – Receiver location vectors (receiver, direction)

  • freq (numpy.ndarray) – Angular frequency vector (frequency)

  • sigs (list of str or dict) – Signal components to superpose.

    1. str: density functions (‘point’, ‘normal’, ‘skewnormal’)

    2. dict: harmonic functions for noise field (‘isonoise’, ‘noise2D’, ‘noise3D’) with optional parameters.

      sig : str (required) - signal type (‘isonoise’, ‘noise2D’, ‘noise3D’)

      s : float (optional) - local slowness

      a : numpy.ndarray (optional) - cosine coefficients

      b : numpy.ndarray (optional) - sine coefficients

      max_order : int (optional) - maximum order of harmonic basis (if a/b not specified)

      dim : int (required for ‘isonoise’, default 2) - cylindrical (2) or spherical (3) isotropy

  • weight_units (str (default ‘dB’)) – Units of the signal weights in the model vector (‘dB’ or ‘linear’)

  • calc_noise_only (bool (default False)) – Include an additional noise-only calculation

  • custom_cf (dict (default {})) – Custom characteristic functions keyed by signal name, containing tuple of number of parameters and function with arguments:

    t numpy.ndarray : Characteristic function argument (frequency, receiver pair, direction)

    m_s numpy.ndarray : Model vector (model, parameter)

    and returns:

    cf numpy.ndarray : Characteristic function (model, frequency, receiver pair)

    dcf numpy.ndarray) : Characteristic function gradient wrt. model parameters (model, frequency, receiver pair, parameter)

Note

If s, a, or b is unspecified, then treated as free parameters.

cf_point(xi: ndarray, grad: bool = True) → Tuple[ndarray, Dict[str, ndarray]][source]#

Function that returns the characteristic function for a point (plane wave) distribution.

Input:

  • xi (numpy.ndarray) – Location vector (slowness) (model, direction)

  • grad (bool (default True)) – Calculate gradients

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name.

    • xi : (numpy.ndarray) – (model, frequency, receiver pair, direction)

The characteristic function for a point (plane wave) distribution is given by

\[\varphi_\mathbf{s} \left(\mathbf{t} ; \mathbf{\xi}\right) = \exp \left[i \mathbf{t}^T \mathbf{\xi}\right]\]

where \(\mathbf{t}\) is the characteristic function argument (frequency, receiver pair, direction) and \(\mathbf{\xi}\) is the location vector (slowness).

The gradients of the characteristic function are given by the following expression:

\[\frac{\partial \varphi_\mathbf{s}}{\partial \xi_i} = i t_i \varphi_\mathbf{s}\]

Function that returns the characteristic function for a normal distribution.

Input:

  • xi (numpy.ndarray) – Location vector (model, direction)

  • sigma (numpy.ndarray) – Scale vector (model, direction)

  • Omega_z (numpy.ndarray) – Correlation matrix (model, direction, direction)

  • grad (bool (default True)) – Calculate gradients

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name:

    • xi : (numpy.ndarray) – (model, frequency, receiver pair, direction)

    • sigma : (numpy.ndarray) – (model, frequency, receiver pair, direction)

    • corr : (numpy.ndarray) – (model, frequency, receiver pair, direction pair)

Note

The correlation matrix is already flattened to upper triangle of Omega_z

The characteristic function for a normal distribution is given by

\[ \begin{align}\begin{aligned}\varphi_\mathbf{s} \left(\mathbf{t} ; \mathbf{\xi}, \Omega\right) = \exp \left[i \mathbf{t}^T \mathbf{\xi} - \frac{1}{2} \mathbf{t}^T \Omega \mathbf{t}\right]\\\Omega = W \Omega_z W\\W = \mathrm{diag} \left(\mathbf{\sigma}\right)\\\Omega_z = \left\|\rho_{ij}\right\|\end{aligned}\end{align} \]

where \(\mathbf{t}\) is the characteristic function argument (frequency, receiver pair, direction), \(\mathbf{\xi}\) is the location vector (slowness), \(\Omega\) is the covariance matrix, \(W\) is the diagonal scale matrix, and \(\Omega_z\) is the correlation matrix. The gradients of the characteristic function are given by the following expressions:

\[ \begin{align}\begin{aligned}\frac{\partial \varphi_\mathbf{s}}{\partial \xi_i} = i t_i \varphi_\mathbf{s}\\\frac{\partial \varphi_\mathbf{s}}{\partial \sigma_i} = - \sum_j rho_{ij} \sigma_j t_i t_j \varphi_\mathbf{s}\\\frac{\partial \varphi_\mathbf{s}}{\partial \rho_{ij}} = - \sigma_i \sigma_j t_i t_j \varphi_\mathbf{s}\end{aligned}\end{align} \]

cf_skewnormal(xi: ndarray, sigma: ndarray, Omega_z: ndarray, alpha: ndarray, grad: bool = True) → Tuple[ndarray, Dict[str, ndarray]][source]#

Function that returns the characteristic function for a skew-normal distribution.

Input:

  • xi (numpy.ndarray) – Location vector (model, direction)

  • sigma (numpy.ndarray) – Scale vector (model, direction)

  • Omega_z (numpy.ndarray) – Correlation matrix (model, direction, direction)

  • alpha (numpy.ndarray) – Shape vector (model, direction)

  • grad (bool (default True)) – Calculate gradients

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name:

    • xi : (numpy.ndarray) – (model, frequency, receiver pair, direction)

    • sigma : (numpy.ndarray) – (model, frequency, receiver pair, direction)

    • corr : (numpy.ndarray) – (model, frequency, receiver pair, direction pair)

    • alpha : (numpy.ndarray) – (model, frequency, receiver pair, direction pair)

Note

The correlation matrix is already flattened to upper triangle of Omega_z.

The characteristic function for a skew-normal distribution is given by

\[ \begin{align}\begin{aligned}\varphi_\mathbf{s} \left(\mathbf{t} ; \mathbf{\xi}, \Omega, \mathbf{\alpha}\right) = \exp \left[i \mathbf{t}^T \mathbf{\xi} - \frac{1}{2} \mathbf{t}^T \Omega \mathbf{t}\right] \left[1 + i \erfi \left(\frac{\sqrt{2}}{2} \mathbf{\delta}^T W \mathbf{t}\right)\right]\\\Omega = W \Omega_z W\\W = \mathrm{diag} \left(\mathbf{\sigma}\right)\\\Omega_z = \left\|\rho_{ij}\right\|\\\mathbf{\delta} = \frac{\Omega_z \mathbf{\alpha}}{\sqrt{1 + \mathbf{\alpha}^T \Omega_z \mathbf{\alpha}}}\end{aligned}\end{align} \]

where \(\mathbf{t}\) is the characteristic function argument (frequency, receiver pair, direction), \(\mathbf{\xi}\) is the location vector (slowness), \(\Omega\) is the covariance matrix, \(W\) is the diagonal scale matrix, \(\Omega_z\) is the correlation matrix, and \(\mathbf{\delta}\) is the skewness-direction vector. The gradients of the characteristic function are given by the following expressions:

\[ \begin{align}\begin{aligned}\frac{\partial \varphi_\mathbf{s}}{\partial \xi_i} = i t_i \varphi_\mathbf{s}\\\frac{\partial \varphi_\mathbf{s}}{\partial \sigma_i} = - \sum_j \rho_{ij} \sigma_j t_i t_j \varphi_\mathbf{s} + \sqrt{\frac{2}{\pi}} i \exp \left[u^2 + L\right] \delta_i t_i\\u = \frac{\sqrt{2}}{2} \mathbf{\delta}^T W \mathbf{t}\\L = i \mathbf{t}^T \mathbf{\xi} - \frac{1}{2} \mathbf{t}^T \Omega \mathbf{t}\\\frac{\partial \varphi_\mathbf{s}}{\partial \rho_{ij}} = - \sigma_i \sigma_j t_i t_j \varphi_\mathbf{s} + \sqrt{\frac{2}{\pi}} i N \exp \left[u^2 + L\right] \left(\sigma_i t_i \alpha_j + \sigma_j t_j \alpha_i - N^2 \alpha_i \alpha_j \sum_{k, l} \sigma_k t_k \rho_{kl} \alpha_l\right)\\N = \left(1 + \mathbf{\alpha}^T \Omega_z \mathbf{\alpha}\right)^\tfrac{-1}{2}\\\frac{\partial \varphi_\mathbf{s}}{\partial \alpha_i} = \sqrt{\frac{2}{\pi}} i \exp \left[u^2 + L\right] \sum_{j, k, l} \sigma_j t_j \left(\rho_{ji} N - \rho_{il} \alpha_l \rho_{jk} \alpha_k N^3\right)\end{aligned}\end{align} \]
cf_isonoise(s: ndarray | float, dim: int = 2, grad_s: bool = False, fixed_key: tuple | None = None) → Tuple[ndarray, Dict[str, ndarray]][source]#

Function that returns the characteristic function for an isotropic noise field.

Input:

  • s (numpy.ndarray or float) – Local slowness (model)

  • dim (int (default 2)) – Dimensions of noise (2 or 3)

  • grad_s (bool (default False)) – Calculate gradient wrt. s

  • fixed_key (tuple (optional)) – Cache key; supplied only when s is held fixed

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name:

    • s : (numpy.ndarray) – (model, frequency, receiver pair)

The characteristic function for an isotropic noise field is given by

\[\begin{split}\varphi_{\mathbf{s}}(\mathbf{t};S_{tr}) = \begin{cases} J_0\left(\ S_{tr} |\mathbf{t}\| \right), & \text{2D (cylindrical)} \\ j_0\left(\ S_{tr} |\mathbf{t}\| \right), & \text{3D (spherical)} \end{cases}\end{split}\]

where \(J_0\) is the Bessel function of order 0 and \(j_0\) is the spherical Bessel function of order 0. The gradients of the characteristic function are given by the following expressions:

\[\begin{split}\frac{\partial \varphi_{\mathbf{s}}}{\partial S_{tr}} = \begin{cases} -|\mathbf{t}\| J_1 \left(\ S_{tr} |\mathbf{t}\| \right), & \text{2D (cylindrical)} \\ -|\mathbf{t}\| j_1 \left(\ S_{tr} |\mathbf{t}\| \right), & \text{3D (spherical)} \end{cases}\end{split}\]

Function that returns the characteristic function for a 2D isotropic noise field.

Input:

  • a, b (numpy.ndarray) – Cosine / sine components ([model], order)

  • s (numpy.ndarray or float) – Local slowness ([model])

  • grad_ab, grad_s (bool) – Calculate gradients

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name:

    • a : (numpy.ndarray) – (model, frequency, receiver pair, order)

    • b : (numpy.ndarray) – (model, frequency, receiver pair, order)

    • s : (numpy.ndarray) – (model, frequency, receiver pair)

The characteristic function for a 2D isotropic noise field is given by

\[\varphi_{\mathbf{s}}(\mathbf{t}, \phi; S_{tr}, \mathbf{b}, \mathbf{b}) = \sum_{m=0}^{M} i^m \epsilon_m C_m (\phi; a_m , b_m) J_m(S_{tr} |\mathbf{t}\|)\]

where \(C_m = a_m \cos(m \phi) + b_m \sin(m \phi)\) and \(J_m\) is the Bessel function of order \(m\). The gradients of the characteristic function are given by the following expressions:

\[\frac{\partial \varphi_{\mathbf{s}}}{\partial a_m} = i^m \epsilon_m \cos(m \phi) J_m(S_{tr} |\mathbf{t}\|)\]
\[\frac{\partial \varphi_{\mathbf{s}}}{\partial b_m} = i^m \epsilon_m \sin(m \phi) J_m(S_{tr} |\mathbf{t}\|)\]
\[\frac{\partial \varphi_{\mathbf{s}}}{\partial S_{tr}} = - \sum_{m=0}^{M} i^m \epsilon_m C_m (\phi; a_m , b_m) S_{tr} J'_m(S_{tr} |\mathbf{t}\|)\]

where

\[ \begin{align}\begin{aligned}\mathbf{\epsilon} = (1, 2, \ldots, 2)\\C_m = a_m \cos(m \phi) + b_m \sin(m \phi)\\J_m '(S_{tr} |\mathbf{t}\|) = \frac{1}{2} \left[ J_{m-1}(S_{tr} |\mathbf{t}\|) - J_{m+1}(S_{tr} |\mathbf{t}\|) \right]\end{aligned}\end{align} \]

Function that returns the characteristic function for a 3D isotropic noise field.

Input:

  • a, b (numpy.ndarray) – Cosine / sine components ([model], order, degree)

  • s (numpy.ndarray or float) – Local slowness ([model])

Output:

  • cf (numpy.ndarray) – Characteristic function (model, frequency, receiver pair)

  • grad_cf (dict) – Gradient of the characteristic function, keyed by parameter name.

    • a : (numpy.ndarray) – (model, frequency, receiver pair, triangle)

    • b : (numpy.ndarray) – (model, frequency, receiver pair, triangle)

    • s : (numpy.ndarray) – (model, frequency, receiver pair)

Note

a and b are already flattened to \(m \leq n\) triangle.

The characteristic function for a 3D isotropic noise field is given by

\[\varphi_{\mathbf{s}}(\mathbf{t}, \phi, \theta; S_{tr}, A, B) = \sum_{n=0}^{N} \sum_{m=0}^{n} i^n C_{nm} (\phi ; A, B) P_n^m(\cos(\theta)) j_n(S_{tr} |\mathbf{t}\|)\]

where \(P_n^m\) is the associated Legendre polynomial of order \(m\) and degree \(n\), and \(j_n\) is the spherical Bessel function of order \(n\). The azimuthal angle \(\phi\) is measured from the x-axis in the xy-plane, and the polar angle \(\theta\) is measured from the z-axis. The coefficients \(A_n^m\) and \(B_n^m\) are the cosine and sine components of the harmonic expansion, respectively. The harmonic coefficient \(C_n^m\) is given by

\[C_n^m = A_n^m \cos(m \phi) + B_n^m \sin(m \phi)\]

The derivatives of the characteristic function with respect to the model parameters are:

\[\frac{\partial \varphi_{\mathbf{s}}}{\partial S_{tr}} = \sum_{n=0}^{N} \sum_{m=0}^{n} i^n C_n^m P_n^m S_{tr} j'_n(S_{tr} |\mathbf{t}\|)\]

where \(j'_n\) is the derivative of the spherical Bessel function of order \(n\) with respect to its argument, and is given by

\[j'_n(S_{tr} |\mathbf{t}\|) ) = \frac{n j_{n-1}(S_{tr} |\mathbf{t}\|) - (n+1) j_{n+1}(S_{tr} |\mathbf{t}\|)}{2n + 1}\]
\[\frac{\partial \varphi_{\mathbf{s}}}{\partial A_n^m} = i^n \cos(m \phi) P_n^m j_n(S_{tr} |\mathbf{t}\|)\]
\[\frac{\partial \varphi_{\mathbf{s}}}{\partial B_n^m} = i^n \sin(m \phi) P_n^m j_n(S_{tr} |\mathbf{t}\|)\]

Compute the covariance and its gradient with respect to the model parameters.

  • grad (bool (default True)) – Calculate gradients

Output:
