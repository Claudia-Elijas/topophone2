3.2 Reading the config.ini file#

In this notebook we demonstrate how to…

  • populate a configuration file

  • read the file

  • access entries

The only utility function we require is parse_config, and we imported as shown below:

[1]:

#__ Import: Topophone2 __
from topophone2.utils.read import parse_config

Hello from topophone2!

Contents of the configuration file#

The configuration file config.ini [saved in path: “../data/config_demo/config.ini”] will look as shown below…

# ================================= #
# ................................. #
# Configuration file for TopoPhone2 #
# ................................. #
# ================================= #

# =============================== #
# data section                    #
# =============================== #
# signal_data_path: Path to the text file containing signal data.
# noise_data_path (optional): Path to the text file containing noise data.
[data]
signal_data_path = ../data/config_demo/data_input.txt
#noise_data_path = ../data/config_demo/noise_data_input.txt

# =============================== #
# signal_model section            #
# =============================== #
# sensor_positions: Path to the CSV file containing sensor positions [m].
# angular_freq: Path to the CSV file containing angular frequencies [rad.s-1].
# signals: Comma-separated list of signal types (e.g., point, skewnormal).
# weight_units: Units for weighting (e.g., dB, linear).
[signal_model]
signals = normal, normal, point
weight_units = dB

# =============================== #
# noise_model section             #
# =============================== #
# signal_noise: Type of noise model (e.g., isonoise, noise2D, noise3D).
# dim (optional): Dimensions of the ISOTROPIC noise maodel (e.g., 2, 3).
# s (optional): local slowness [s.m-1] (float).
# a (optional): list of cosine coefficients [-].
# b (optional): list of sine coefficients [-].
# max_order (optional): max order of harmonic basis if 'a' and 'b' are NOT specified.
# sensor_selfnoise: whether to account for sensor self-noise (bool, e.g., True, False).
[noise_model]
signal_noise = noise3D
#dim = 1
s = 2.1
a = 0.5, 0.2
b = 0.5, 0.3
#max_order = 10
sensor_selfnoise = False

# =============================== #
# prior_pdf section               #
# =============================== #
# prior_bounds: Path to the CSV file containing prior bounds for the parameters.
[prior_pdf]
prior_bounds = ../data/config_demo/prior_bounds.csv

# =============================== #
# inversion section               #
# =============================== #
# N_flow: Number of normalizing flows.
# mean_field: Whether to use mean field approximation (bool).
# ini_dist: Initial distribution for the inversion (bool).
# learning_rate: Learning rate for the inversion (float).
# N_iterations: Number of iterations for the inversion (int).
# N_montecarlo: Number of samples for the inversion (int).
# N_out: Number of output samples for the inversion (int).
# verbose: Whether to print verbose output during the inversion (bool).
# N_samples: Number of posterior samples to generate (int).
# calc_likelihood: Whether to calculate the likelihood during the inversion (bool).
[inversion]
N_flow = 4
mean_field = False
ini_dist = Uniform
learning_rate = 0.001
N_iterations = 1000
N_montecarlo = 1000
N_out = 20
verbose = True
N_samples = 1000
calc_likelihood = True

# =============================== #
# save_out section                #
# =============================== #
# model_outpath: Path to the directory where the results of the inversion will be saved.
[save_out]
model_outpath = ./output/model_out

Loading the file#

[2]:

args_dict = parse_config("../data/config_demo/config.ini")


No noise data file specified in config file. Setting Gamma_obs_noise to None.

Accessing entries of the file#

The parser function returns a dictionary with keys that correspond to the arguments of the topophone2.topophone.decomposition function, which performs probabilistic wavefield decomposition from a single call.

[3]:

for key, value in args_dict.items():
    print(f"{key} ")

We can access a given key as shown below,

[4]:

N_obs = args_dict['N_obs'] ; print(f"N_obs: {N_obs}")

N_obs: 200

Feeding configuration entries into the decomposition function#

The keys returned by parse_config are in the same order as the arguments of decomposition, we can simply input them as

decompose = (**args_dict)
