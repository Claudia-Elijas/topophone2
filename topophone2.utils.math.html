Mathematics#

The topophone2.utils.math module provides mathematical convenience functions.

topophone2.utils.math.bessel_function(argument: float | ndarray, order: int = 0, shape: str = 'cylindrical', derivative: bool = False)[source]#

Calculate Bessel function (derivative).

Input:

  • argument (float or numpy.ndarray) – Argument to Bessel function

  • order (int (default 0)) – Order of Bessel function (can broadcast)

  • shape (str (default 'cylindrical')) – Shape of Bessel function ('cylindical' for J, 'spherical' for j)

  • derivative (bool (default False)) – Return derivative of the Bessel function

Output:

numpy.ndarray – Function output

topophone2.utils.math.legendre_polynomial(argument: ndarray, degree: int, order: int, condon_shortley: bool = False)[source]#

Function to compute the associated Legendre polynomial \(P_n^m\left(x\right)\).

Input:

  • argument (numpy.ndarray) – Argument to polynomial

  • degree (int) – Degree of polynomial (n)

  • order (int) – Order of polynomial (m)

  • condon_shortley (bool (default False)) – Include the Condon-Shortley phase $(-1)^m$

Output:

numpy.ndarray – Polynomial

topophone2.utils.math.density_params(xi: ndarray, sigma: ndarray = None, corr: ndarray = None, alpha: ndarray = None)[source]#

Construct summary quantities for density functions (point, normal, skewnormal) in cylindrical/spherical coordinates.

Input:

  • xi (numpy.ndarray) – Location vector [s.m-1] (model, direction)

  • sigma (numpy.ndarray (optional)) – Scale vector [s.m-1] (model, direction)

  • corr (numpy.ndarray (optional)) – Correlation matrix off-diagonal (upper-triangle order) (model, direction pair)

  • alpha (numpy.ndarray (optional)) – Shape vector [dimensionless] (model, direction)

Output:

  • wd (numpy.ndarray) – Skewness-direction vector [s.m-1] (model, direction)

  • mean (numpy.ndarray) – Mean vector [s.m-1] (model, direction)

  • xi_circ (numpy.ndarray) – Location vector in cylindrical/spherical coordinates [s.m-1, deg from North[, deg from horizontal]] (model, direction)

  • mean_circ (numpy.ndarray) – Mean vector in cylindrical/spherical coordinates [s.m-1, deg from North[, deg from horizontal]] (model, direction)

  • sigma_circ (numpy.ndarray) – Standard deviation along the local radial, azimuthal[, elevation] directions at the location [s.m-1, deg[, deg]] (model, direction)

  • wd_circ (numpy.ndarray) – Skewness-direction vector along the local radial, azimuthal[, elevation] directions at the location [s.m-1, deg[, deg]] (model, direction)

topophone2.utils.math.density_function(s: tuple, xi: ndarray, sigma: ndarray, corr: ndarray = None, alpha: ndarray = None) → ndarray[source]#

Evaluate the normal or skew-normal probability density on a slowness grid.

Input:

  • s (tuple of numpy.ndarray) – Slowness grid from np.meshgrid [s.m-1], one array per direction (*grid) each

  • xi (numpy.ndarray) – Location vector [s.m-1] (model, direction)

  • sigma (numpy.ndarray) – Scale vector [s.m-1] (model, direction)

  • corr (numpy.ndarray (optional)) – Correlation matrix off-diagonal (upper-triangle order) (model, direction pair)

  • alpha (numpy.ndarray (optional)) – Shape vector [dimensionless] (model, direction)

Output:

p (numpy.ndarray) – Probability density [(s.m-1)^-N_dir] (model, *grid)

topophone2.utils.math.harmonic2D_density(az: ndarray, a: ndarray, b: ndarray, a0: float = 1.0)[source]#

Azimuthal density of a 2D noise field from its cylindrical-harmonic coefficients.

Input:

  • az (numpy.ndarray) – Azimuthal angles [deg, clockwise from North] (angle,)

  • a (numpy.ndarray) – Cosine coefficients ([model,] order)

  • b (numpy.ndarray) – Sine coefficients ([model,] order)

  • a0 (numpy.ndarray (default 1.0)) – Zeroth-order coefficient ([model,])

Output:

rho (numpy.ndarray) – Normalised azimuthal density [rad-1] (model, angle)
